## 已确认 / 待核实 分界

**已确认事实（来自发现报告）**

- 牵头：区域运营总监顾明岚推动立项并决定试点范围与节奏；设施安全经理傅景有安全否决权；供应商协调员叶书参与服务结果验收。
- 预算：首期 14 万元（集成、培训、验证），收益需扣除维护与人工复核成本。
- 角色：6 类关键角色（顾明岚、林亦舟、唐映秋、秦芮、傅景、叶书）。
- 业务量：每季度 12 店、每店约 140 项任务、每周汇总 6 小时、每小时更新已授权业务状态。
- 系统：项目管理表 / 供应商平台 / 设备台账，权限独立、无统一视图；只读接口可读任务与文档，不写回验收/付款；中断用带时间戳的只读快照标「暂未更新」。
- 试点：3 家新店，关键依赖识别完整率 ≥95%，安全验收漏项为零。

**待核实（未核实前不得当作结论）**

- 总用户数、日活、并发数、日请求/工单量。
- 部署形态（云端/内网/第三方）、系统间是否同步、接口鉴权与调用频率。
- **能不能上云（一票否决项）**：是否允许上云、是否必须私有化，报告均未核实。
- 依赖识别准确率、误判率、交接等待时长基线；95% 统计口径；签字权限与留存到期审批人。

## 「能不能上云」核实路径（一票否决项）

1. 顾明岚：确认数据分类分级、授权范围、对外承诺边界。
2. 秦芮：确认三套系统部署环境、接口鉴权方式、调用频率、系统间同步情况。
3. 傅景：确认消防/用电/食品设施验收红线、「暂未更新」期间必须暂停的验收动作、90 天留存到期后的复核与删除审批。
4. 结论落定前：只走只读接入 + 脱敏 + 历史资料回放；不写回验收、不代签工程验收、不触发付款。

## 试点红线（不可放宽）

- 消防、用电、食品设施验收不可跳过；违规项不得标记完成。
- AI 只做提示与汇总，不代签工程验收、不自动签署供应商验收或付款。
- 有歧义的数据进人工修复队列，不进自动推荐样本。
- 接口中断用带时间戳的只读快照并标「暂未更新」，重连后按业务编号去重补齐。
- 评价记录暂留 90 天，期满由设施安全经理复核删除或归档。
