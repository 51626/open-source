# store-opening-preparation · 开店筹备与运营验收

青杉生活超市「新店开门前的百项清单」场景 —— 业务需求发现与现状流程梳理。

> 本仓库内容基于合成场景访谈产出，需求均为**待验证假设**。采集完整不等于真实业务需求已确认。

```

```

## 核心结论速览

| # | 候选需求 | 优先级 | 待确认负责人 |
|---|---------|-------|------------|
| 1 | 跨群关键依赖识别与影响提示 | P0 | 筹备项目专员 唐映秋 |
| 2 | 统一「完成」口径与分岗完成时间 | P0 | 供应商协调员 叶书 + 筹备项目专员 |
| 3 | 数据质量校验与人工修复队列先行 | P0 | 门店平台工程师 秦芮 |
| 4 | 只读接口与快照兜底（不得写回验收） | P1 | 门店平台工程师 秦芮 |
| 5 | 转人工触发条件与留痕清单 | P1 | 设施安全经理 傅景 |
| 6 | 反馈闭环绑定原业务编号与资料版本 | P2 | 供应商协调员 叶书 |

**建议切入点**：REQ-1 — 以「依赖识别与筹备提醒」先做历史资料回放，不触碰验收签署与付款。

## 关键约束（红线）

- 消防、用电、食品设施验收不可跳过，违规项不得标记完成。
- AI 只做提示与汇总，**不代签工程验收、不触发付款**。
- 有歧义的数据进人工修复队列，不进自动推荐样本。
- 接口中断时用带时间戳的只读快照，并标注「暂未更新」。

## 试点验收标准

- 3 家新店试点
- 关键依赖识别完整率 ≥ 95%
- 安全验收漏项为零
- 首期预算 14 万元（含集成、培训与验证）
