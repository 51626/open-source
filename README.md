## 关键假设（必须随报价单一起说明）

1. **上云路线 = 按 API 路线测算（假设）。** 《项目一页纸》中「能不能上云」仍是一票否决项未决——发现报告只确认「可读任务与文档、不写回验收/付款」，未确认是否允许数据上云。本报价按「脱敏后可调用云端 API」测算模型与服务器成本。
   - 若客户确认**不可上云**，须改私有化重算：按 32B INT8 估算，权重 32 GB + KV Cache(4K×16 路)约 16 GB，合计 (32+16)×1.15 ≈ 55 GB，单卡 A100/H100 80G 云租约 7,000 元/月，服务器年成本将从 3,000 元升至约 84,000 元，首年报价需整体重算。
2. **范围限定为首期试点**：3 家新店、REQ-1「跨群关键依赖识别与影响提示」，先做历史资料回放，不触碰验收签署与付款。每季度 12 店的复用属于后续扩量，按超量另计。
3. **业务量**：月均约 4 店、每店约 140 项任务 → 月均约 560 项（由「每季度 12 店 × 140 项」折算）。日请求量无基线，故按“月任务数”而非“日请求数”作为 Token 测算起点。
4. **单价口径**：FDE 2,450 元/天直接取测算器导出值；其余角色用同一口径（月薪 × 1.55 ÷ 21.75 ÷ 利用率 80% × 1+25%）推导后取整。加成率 25% ≈ 实际毛利率 20%，二者不可混用。
5. **成本加成与风险预留分开列**：风险预留 10%（需求已四来源收敛、有硬验收标准，取区间下限），成本加成 25%。对外报价 = 五块合计 × 1.10 × 1.25。

## 报价模式选择

**项目总价制**（四选一）。范围清晰（3 店试点 / REQ-1 依赖识别）且有硬验收标准（关键依赖识别完整率 ≥95%、安全验收漏项为零），适合一口价交付；首期预算 14 万已知，便于对齐。风险集中在我方（延期、返工自扛），因此落单时按课件推荐的组合结构出单：一次性实施费 106,645 元 + 年服务费 32,175 元/年，并把超量单价、调优轮次、验收标准写进合同，控制返工与扩量风险。
